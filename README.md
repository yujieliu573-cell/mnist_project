# Level 1.2 MNIST 手写数字识别与对比实验

本项目基于 PyTorch 构建了一个多层感知机（MLP），完成了经典的 MNIST 手写数字识别任务。并在此基础上，使用“控制变量法”进行了四组对比实验，以观察不同网络设计与超参数对模型性能的影响。

## 1. 实验环境
- **操作系统**：Windows WSL 2 (Ubuntu)
- **Python 环境**：Conda (Python 3.10)
- **核心库**：PyTorch, Torchvision, Matplotlib
- **计算设备**：CPU

## 2. 基准模型 (Baseline)
- **网络结构**：Flatten -> Linear(28*28, 512) -> ReLU -> Linear(512, 256) -> ReLU -> Linear(256, 10)
- **损失函数**：CrossEntropyLoss（交叉熵损失）
- **优化器**：Adam (Learning Rate = 0.001)
- **训练设置**：Batch Size = 64，Epochs = 5，每 100 Step 记录一次 Validation Accuracy。
- **实验结果**：最终验证集准确率稳定在 **97.0%** 左右。曲线见 `results/baseline_curves.png`。

## 3. 对比实验设计与结果分析
*注：每次实验仅修改一个条件，其他设置与 Baseline 保持绝对一致。*

### 实验一：修改激活函数（ReLU -> Sigmoid）
- **设计**：将模型中的 ReLU 替换为 Sigmoid。
- **结果**：最终准确率依然能达到 **97.0%** 左右，但曲线轨迹与 Baseline 相似。
- **分析**：由于网络较浅（仅 2 层隐藏层），且 Adam 优化器鲁棒性极强，Sigmoid 导致的“梯度消失”问题被很大程度上掩盖了。模型依然成功收敛，说明在简单任务下，激活函数的替换不足以引发质变。

### 实验二：调整训练超参数（重点：修改学习率）
- **设计**：调整 Adam 优化器的 Learning Rate（如从 0.001 放大到 0.01 或 0.1）。
- **结果**：**出现了非常显著的差异！** 曲线表现与 Baseline 截然不同（Loss 可能剧烈震荡，或收敛速度发生明显改变）。
- **分析**：学习率是深度学习中极其重要的超参数。学习率过大导致模型无法收敛或 Loss 剧烈震荡；学习率过小则导致训练缓慢。这一实验直观地证明了：**在固定的网络结构下，优化器的步长（学习率）往往比微调网络结构更能决定训练的成败。**

### 实验三：修改网络结构（加深网络层数）
- **设计**：增加一层隐藏层（如 512 -> 256 -> 128 -> 10）。
- **结果**：准确率无明显提升，依旧在 **97.0%** 上下浮动，甚至 Loss 曲线震荡频率变高。
- **分析**：MNIST 任务属于极其简单的视觉任务，原 Baseline 的参数量已足够拟合该分布。盲目加深网络不仅没带来性能提升，反而增加了计算开销，存在轻微的过拟合风险。

### 实验四：修改损失函数（CrossEntropy -> NLLLoss）
- **设计**：在模型 `forward` 末尾添加 `LogSoftmax` 层，并将损失函数替换为 `nn.NLLLoss()`。
- **结果**：曲线与 Baseline **完全一致**。
- **分析**：在 PyTorch 中，`CrossEntropyLoss` 等价于 `LogSoftmax` + `NLLLoss`。本实验验证了数学上的等价性，也提醒我们在替换损失函数时，必须注意模型输出层的数据格式。

## 4. 核心结论
1. **不要迷信“改结构”**：在简单任务中，微调网络深度或更换激活函数，差异可能微乎其微。
2. **重视超参数**：学习率的调整直接决定了模型能否找到最优解，其对 Loss 曲线和训练过程的影响远大于简单的层数叠加。
3. **理论联系实际**：NLLLoss 与 CrossEntropy 的等价实验，验证了底层数学原理。
